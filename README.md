# Проектная работа 4 спринта

Проект асинхронного API кинотеатра. Реализованы методы для просмотра информации о фильмах, поиска фильмов по ключевым
словам, поиска похожих по жанру фильмов.

Используемые технологии: Python + FastAPI, uvicorn, ElasticSearch, Redis, Docker

Проект выполняется индивидуально

[Ссылка на репозиторий](https://github.com/nyutamaksimova/Async_API_sprint_1)

Проект содержит пример файла .env, запуск производится с помощью команды `docker-compose up --build`

URL Swagger-документации `/api/openapi`. Описание api в json: `/api/openapi.json`
